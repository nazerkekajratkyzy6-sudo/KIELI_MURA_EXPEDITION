# КИЕЛІ МҰРА — Құпиялар ізімен

Интерактивная историко-краеведческая экспедиция на казахском языке.

## Публикация

1. Создайте пустой GitHub-репозиторий.
2. Загрузите **содержимое этой папки** в корень репозитория: `index.html`, `app.js`, `vercel.json`, `assets/`.
3. В Vercel выберите **Add New → Project → Import Git Repository**.
4. Framework Preset: **Other**. Build Command: **пусто**. Output Directory: **.**.
5. Нажмите **Deploy**.

Работает без серверной части, регистрации, API-ключей и платной базы данных. Шрифты Google Fonts требуют подключения к интернету; при отсутствии сети используются резервные шрифты.

## Содержание

- Кинематографический главный экран с эффектом параллакса.
- Два маршрута с фотографиями из исходной научной работы.
- Четырёхэтапная интерактивная фотоэкспедиция.
- Пять вопросов «Аңыз бен ақиқат» с объяснениями.
- Подлинные цифры исходного анкетирования 20 человек.
- Дневник исследования с копированием или сохранением в TXT.

## Ограничения

Это фотоэкспедиция, не реальная 3D-панорама. Результаты вопросов не сохраняются на сервере и не являются новым экспериментом. Исторические утверждения основаны на переданном документе; отдельные сведения нуждаются в независимой проверке. Фотографии из работы следует публиковать только при наличии права на их использование.
